- [minor] src/hooks.ts:200 the guard trusts the command string to say whether the commit sweeps the working tree. A commit written as `git -c x=y commit --all` or with the flag after the message still matches, but a shell alias or a script that runs git commit indirectly does not reach this check at all. The hook covers the assistant's own tool calls, which is its stated scope, and it is worth remembering that scope is not the whole repository.
- [minor] src/hooks.ts:203 the refusal names up to three files and counts the rest. On a large accidental staging the human sees three names and a number, which is enough to know something is wrong but not enough to know what. Matches how the scope check reports, so the inconsistency would be in changing it.
