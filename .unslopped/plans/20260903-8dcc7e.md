# Add unslopped --version and -v

Cycle: 20260903-8dcc7e

## Goal
Running `unslopped --version`, `unslopped -v`, or `unslopped version` prints the package version and exits 0. The number comes from the installed package, so it always matches what is running.

## Approach
Chosen: read the version from package.json next to the compiled module, using import.meta.url so it resolves from dist. Add an early check in main that prints the version for the version command, the -v command, or the --version and -v flags, then returns 0. Add a help line. This is a one-file change plus a test.
Rejected: hardcoding the version string, because it would drift from package.json.

- A build-time version stamp
- Any other command
