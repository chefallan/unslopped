# Install allowlists the safe cycle commands

Cycle: 20260903-955904

## Goal
A hooked assistant runs the whole cycle without the Claude auto mode classifier blocking mechanical commands. `unslopped install` writes permission allowlist rules for the safe advance commands: commit, next, red, propose, start, in both the bare and npx forms. It does not allowlist approve, reset, or rollback, so those keep raising the prompt. `unslopped uninstall` removes exactly the rules install added.

## Approach
Chosen: extend mergeClaudeSettings to add a fixed ALLOW list to settings.permissions.allow, deduped against existing entries, and stripClaudeSettings to remove exactly those entries. The rule strings use the Claude prefix form, for example Bash(unslopped commit:*). The list holds only the mechanical cycle commands. approve, reset and rollback stay off the list on purpose, because the allowlist would let them run without the prompt. Bump to 0.1.2 and document the rules and the reasoning. Revisable if more commands need adding later.
Rejected: allowlisting every unslopped subcommand, because that would include approve and defeat the one-click prompt. Rejected: having the assistant edit settings.json, because the classifier correctly blocks an AI from granting its own permissions; the human runs install.

## Out of scope
- Cursor permission rules, which use a different model
- Any change to the hook or approval behavior
