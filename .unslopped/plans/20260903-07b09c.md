# Protocol tells hooked assistants to run approve, not delegate it

Cycle: 20260903-07b09c

## Goal
The protocol phase rows agree with the one-click rule. A hooked assistant runs the approve command itself so the harness prompts the human. The deploy row stops saying "tell the human to run approve deploy" and "never run approve yourself". The release row stops saying "ask the human to run approve commit". Version bumps to 0.1.1.

## Approach
Chosen: rewrite the deploy and release rows to say the assistant runs the approve command, which raises the prompt on a hooked assistant, and to ask the human only when not hooked. A test reads protocolBody and fails if a phase row still tells the human to run approve or forbids the assistant from running it. Bump package.json to 0.1.1 and add a changelog entry. This is revisable if the wording needs tuning.
