# Keep commits authored by the human only

Cycle: 20260901-3b9ebc

## Goal
Every commit in a cycle carries the human as its only author. Assistant identities never appear as author or committer, assistant co-author trailers and "generated with" badge lines never reach a commit message, and the release gate proves it. Human co-authors remain welcome.

## Approach
Chosen: two mechanical layers sharing one assistant-identity pattern. The tool hook denies a git commit command that carries an assistant co-author trailer before it runs, which matters because assistants are configured by their vendors to add those trailers. The release gate scans every commit since cycle start (author, committer, body lines) and fails on assistant identities, assistant co-author trailers, or generated-with badges, naming the offending line so the human can amend. Behind practices.humanAuthorship, on by default. The protocol states the rule so well-behaved assistants never hit the hook.
Rejected: pinning authorship to one configured email, because shared branches legitimately carry several humans and the point is no assistants, not one person. Rejected: rewriting commit messages automatically, because unslopped verifies and refuses; it does not edit history behind anyone's back.

## Out of scope
- Server-side enforcement (branch protection or a GitHub App would be needed for pushes made outside unslopped)
- Scanning history older than the cycle
- PR body scrubbing (unslopped writes those bodies itself and adds no attribution)
